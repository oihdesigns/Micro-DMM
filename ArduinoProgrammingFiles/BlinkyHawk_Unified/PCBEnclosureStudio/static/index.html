Your enclosure workflow

  1. Import a KiCad or STEP board. Set wall, floor, clearance, and height in Enclosure. KiCad courtyard bodies are estimates. STEP imports retain the actual component solids; verify the detected substrate in PCB properties.
  2. Add features. Select a component, then add a window, hole, or boss. Or start from a world plane or enclosure surface. Offsets U/V/N follow the attachment frame.
  3. Use exact reference faces. Add STEP, position it with translation/rotation, then choose Attach to face. Click a flat reference face. STL/3MF references are display meshes; use custom planes for them.
  4. Make construction planes. Attach a plane to a component, another plane, a STEP face, or the origin. Move and rotate it, then attach features to it.
  5. Check and export. Resolve failed features and inspect collision warnings. Export shell and lid as 3MF, STL, or STEP, and save a portable .pcbshell project.

This first version supports dimensioned primitive and polygon features, not a general sketch-constraint solver. Collision checks use actual solids for STEP boards and component envelopes for KiCad boards. Separate reference models are not included. Test-print before a production run.
