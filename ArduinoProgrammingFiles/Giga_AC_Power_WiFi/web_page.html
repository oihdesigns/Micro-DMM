Add a network
The board tries the built-in networks (arduino_secrets.h) first, then the saved ones, and joins the first one in range. Saving writes the board's flash: it pauses for about 1 s and needs the load relay open. With no known network in range it starts its own hotspot GigaPower: join that and open http://192.168.3.1:8080/. The hotspot password is on the board's OLED.

Read-only except the load relay, the current range and the Wi-Fi networks. There is no login yet: anyone on this network can open this page and change them.
